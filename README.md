# DineEase-Restaurant-Managagement
DineEase is a Java-based Restaurant Management System built using Java Swing, JDBC, and MySQL. It provides features for menu management, customer order creation, order history, and bill generation. The project demonstrates CRUD operations, database connectivity, transaction handling, and a user-friendly interface for efficient restaurant management
